## 1. ทะเบียน / ใบอนุญาต ในไทย

### 1.1 ❓ ทะเบียนธุรกิจ "ตลาดแบบตรง" กับ สคบ. — สำคัญที่สุด

| | |
|---|---|
| กฎหมาย | พ.ร.บ.ขายตรงและตลาดแบบตรง พ.ศ. 2545 |
| ทำไมเกี่ยว | **มาตรา 3** นิยาม "ตลาดแบบตรง" = การทำตลาดสินค้าโดยสื่อสารข้อมูลเสนอขายตรงต่อผู้บริโภค — การขายผ่านเว็บไซต์เข้าข่าย |
| หน้าที่ | **มาตรา 38** ต้องจดทะเบียนต่อนายทะเบียน (สคบ.) ก่อนประกอบธุรกิจ + วางหลักประกัน |
| โทษ | จำคุกไม่เกิน 1 ปี หรือปรับไม่เกิน 100,000 บาท หรือทั้งจำทั้งปรับ + ปรับรายวันอีกวันละ 10,000 บาท จนกว่าจะเลิกฝ่าฝืน |

**❓ ประเด็นที่ต้องให้ทนายชี้ขาด — อาจได้รับยกเว้น**

มี **กฎกระทรวง (2 พ.ย. 2561)** กำหนดว่าการขายสินค้าทางอิเล็กทรอนิกส์บางลักษณะ **ไม่ถือเป็นตลาดแบบตรง** และมีการยกเว้นให้ผู้ประกอบการ SME

จากแหล่งทุติยภูมิระบุเกณฑ์ไว้ประมาณนี้ (ยังไม่ได้ตรวจตัวบทกฎกระทรวงโดยตรง):
- บุคคลธรรมดา รายได้ไม่เกิน 1.8 ล้านบาท/ปี → ยกเว้น
- นิติบุคคลที่เข้าเกณฑ์ SME ตามกฎกระทรวง → ยกเว้น
- เกณฑ์ SME ค้าปลีก/ค้าส่ง/บริการ: ลูกจ้างไม่เกิน 30 คน **หรือ** รายได้ไม่เกิน 50 ล้านบาท/ปี

> **คำถามถึงทนาย:** บริษัทเข้าเกณฑ์ยกเว้นตามกฎกระทรวง 2561 หรือไม่
> ถ้าเข้า ต้องยื่นแจ้งอะไรกับ สคบ. เพื่อยืนยันสถานะยกเว้นไหม หรือไม่ต้องทำอะไรเลย
> ขอให้ตรวจจากตัวบทกฎกระทรวงโดยตรง ไม่ใช่จากบทความสรุป

### 1.2 ❓ ทะเบียนพาณิชย์อิเล็กทรอนิกส์ (กรมพัฒนาธุรกิจการค้า)

ผู้ประกอบการที่ขายสินค้าผ่านช่องทางออนไลน์เป็นปกติธุระ ต้องจดทะเบียนพาณิชย์อิเล็กทรอนิกส์

> **คำถามถึงทนาย:** บริษัทจดทะเบียนพาณิชย์ (ปกติ) ไว้แล้วหรือยัง และต้องจด
> **ประเภทพาณิชย์อิเล็กทรอนิกส์** เพิ่มหรือไม่ · ต้องยื่นภายในกี่วันนับจากเริ่มขาย · โทษถ้าไม่ยื่น

**ผลพลอยได้ที่เกี่ยวกับงานปัจจุบัน:** จดแล้วขอเครื่องหมาย **DBD Registered** ได้ ซึ่งเอาไปติดบนเว็บ — payment gateway หลายเจ้ามองว่าเป็นสัญญาณความน่าเชื่อถือ

### 1.3 ❓ มาตรฐานสินค้าเฉพาะประเภท

สินค้าที่ขายอยู่มีหมวด **เครื่องสำอาง · ผลิตภัณฑ์บำรุงผิว · สมุนไพร · อาหาร**

> **คำถามถึงทนาย:** การเป็นผู้ส่งออก (ไม่ใช่ผู้ผลิต) ต้องมีใบอนุญาตจาก อย. หรือแจ้ง
> รายละเอียดใด ๆ หรือไม่ · สินค้าหมวดสมุนไพร/เครื่องสำอางมีข้อจำกัดการส่งออกหรือเปล่า

## 2. ภาษี

### 2.1 🔴 VAT — จุดที่เสี่ยงที่สุดในเชิงตัวเงิน

| | |
|---|---|
| เกณฑ์จดทะเบียน | รายได้เกิน **1.8 ล้านบาท/ปี** ต้องจดทะเบียนภาษีมูลค่าเพิ่ม |
| ส่งออก | ได้อัตรา **0%** แทน 7% |

**⚠️ เงื่อนไขที่ต้องระวัง:** จากข้อมูลกรมสรรพากร การส่งออกจะได้ VAT 0% **เฉพาะกรณีที่ผ่านพิธีการศุลกากร** — ส่วนการส่งทางไปรษณีย์หรือหิ้วออกไปโดย**ไม่ผ่านพิธีการศุลกากร ต้องเสีย 7%**

ธุรกิจนี้ส่งพัสดุรายย่อยไปจีน ซึ่งอาจไม่ได้ผ่านพิธีการศุลกากรแบบส่งออกเต็มรูป

> **คำถามถึงทนาย/ผู้สอบบัญชี:** วิธีจัดส่งที่ใช้อยู่ (ระบุผู้ให้บริการขนส่งให้ทนายด้วย)
> เข้าเงื่อนไข VAT 0% หรือไม่ · ต้องเก็บเอกสารอะไรเป็นหลักฐาน (ใบขนสินค้าขาออก ฯลฯ)
> · ถ้าไม่เข้าเงื่อนไข ต้องบวก 7% ในราคาขายหรือรับภาระเอง

**ผลกระทบถ้าตอบผิด:** ขายไป 1 ปีแล้วสรรพากรตีความว่าไม่เข้า 0% = ย้อนเก็บ 7% ของยอดขายทั้งหมด พร้อมเบี้ยปรับเงินเพิ่ม

### 2.2 ❓ ภาษีเงินได้นิติบุคคล + ราคาขายเป็นเงินหยวน

ราคาสินค้าตั้งเป็น CNY แต่รับเงิน settle เป็น THB

> **คำถามถึงผู้สอบบัญชี:** ใช้อัตราแลกเปลี่ยนใดในการรับรู้รายได้ · กำไร/ขาดทุนจาก
> อัตราแลกเปลี่ยนบันทึกอย่างไร · ค่าธรรมเนียม payment gateway หักเป็นค่าใช้จ่ายได้เต็มหรือไม่

## 3. คุ้มครองข้อมูลส่วนบุคคล

### 3.1 🔴 PDPA ไทย — พ.ร.บ.คุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562

บริษัทเป็น **ผู้ควบคุมข้อมูลส่วนบุคคล** เก็บ ชื่อ-เบอร์โทร-ที่อยู่-WeChat ID ของลูกค้า

สิ่งที่ทำไปแล้วบนเว็บ:
- ✅ มีหน้านโยบายความเป็นส่วนตัว ระบุข้อมูลที่เก็บ วัตถุประสงค์ การเปิดเผย และสิทธิของเจ้าของข้อมูล
- ✅ ระบุฐานทางกฎหมาย (ปฏิบัติตามสัญญา ม.24(3) / ปฏิบัติตามกฎหมาย ม.24(6))
- ✅ เปิดเผยการส่งข้อมูลข้ามพรมแดน

**❓ สิ่งที่ยังไม่ได้ทำ ต้องให้ทนายประเมิน**

| | |
|---|---|
| ต้องแต่งตั้ง DPO หรือไม่ | ขึ้นกับลักษณะและปริมาณการประมวลผล |
| บันทึกรายการประมวลผล (RoPA) | ยังไม่มี |
| ข้อตกลงกับผู้ประมวลผลข้อมูล (DPA) | ยังไม่มี — ผู้ให้บริการที่แตะข้อมูลลูกค้า: **Supabase** (ฐานข้อมูล + ที่เก็บไฟล์), payment gateway, ผู้ให้บริการขนส่ง |
| ขั้นตอนรับคำร้องใช้สิทธิ | ยังไม่มีกระบวนการเป็นลายลักษณ์อักษร |
| ขั้นตอนแจ้งเหตุข้อมูลรั่วไหลใน 72 ชม. | ยังไม่มี |
| การขอความยินยอมเรื่อง cookie / analytics | ปัจจุบันเว็บ**ไม่มี** analytics ใด ๆ (ตรวจแล้ว) ถ้าจะติดตั้งภายหลังต้องทำ consent |

### 3.2 🔴 PIPL จีน — มีผลกับบริษัทไทยด้วย

**กฎหมายคุ้มครองข้อมูลส่วนบุคคลแห่ง สปจ. (PIPL)** มีผลนอกอาณาเขต ครอบคลุมผู้ประกอบการนอกจีนที่ประมวลผลข้อมูลของบุคคลในจีนเพื่อให้บริการแก่บุคคลนั้น — ธุรกิจนี้เข้าข่ายเต็ม ๆ

จากรายงานที่ค้นได้ ตั้งแต่ **1 ม.ค. 2569** มีระเบียบว่าผู้ประมวลผลข้อมูลที่อยู่นอกประเทศ**ต้องตั้งหน่วยงานเฉพาะหรือแต่งตั้งตัวแทนในประเทศจีน** และมีระเบียบการรับรองการส่งข้อมูลข้ามพรมแดน โทษปรับสูงสุด **5% ของรายได้ทั่วโลก**

> **คำถามถึงทนาย (ควรเป็นทนายที่ทำงานจีนได้):**
> บริษัทต้องแต่งตั้งตัวแทนในจีนหรือไม่ · มีเกณฑ์ขั้นต่ำ (จำนวนผู้ใช้/ปริมาณข้อมูล) ที่ทำให้ยังไม่เข้าข่ายไหม
> · การส่งข้อมูลลูกค้าจีนมาเก็บที่ Supabase (สิงคโปร์) ต้องใช้กลไกใดรองรับ
> · ต้องแปลนโยบายความเป็นส่วนตัวและขอ consent แยกตามรูปแบบของ PIPL หรือไม่

**หมายเหตุ:** ข้อนี้เป็นข้อที่ผมมั่นใจน้อยที่สุด เพราะเป็นกฎหมายต่างประเทศที่เพิ่งมีระเบียบใหม่ — อย่าเชื่อเอกสารนี้ ให้ทนายตรวจ

## 4. ฝั่งจีน — การนำเข้า

### 4.1 ❓ พิกัดสินค้านำเข้าเพื่อใช้ส่วนตัว (跨境电商零售进口)

จีนมีระบบ cross-border e-commerce retail import ที่มี **positive list** ของสินค้าที่นำเข้าได้ และมีวงเงินต่อครั้ง/ต่อปีต่อผู้ซื้อ

> **คำถามถึงทนาย/ตัวแทนขนส่ง:** สินค้าที่ขาย (อาหาร เครื่องสำอาง สมุนไพร) อยู่ใน positive list หรือไม่
> · วงเงินต่อคำสั่งซื้อและต่อปีของผู้ซื้อคือเท่าไร · ถ้าเกินจะเกิดอะไรขึ้นกับพัสดุ
> · ต้องลงทะเบียนกับศุลกากรจีนในฐานะผู้ขายต่างประเทศหรือไม่

**สิ่งที่ทำไปแล้วบนเว็บ:** ระบบมีฟีเจอร์จำกัดจำนวนสินค้าต่อคำสั่งซื้อ (`maxQtyPerOrder`) อยู่แล้ว — แต่**ยังไม่ได้ตั้งค่าตามเกณฑ์จริงของจีน** เพราะยังไม่รู้เกณฑ์

### 4.2 ✅ ไม่ต้องมี ICP License

เว็บโฮสต์อยู่ที่ฮ่องกง (Alibaba Cloud `cn-hongkong`) ซึ่งอยู่นอกจีนแผ่นดินใหญ่ จึงไม่ต้องยื่น ICP filing
> ถ้าย้ายเซิร์ฟเวอร์เข้าจีนแผ่นดินใหญ่เมื่อไร ต้องมี ICP ทันที และต้องมีนิติบุคคลจีน

## 5. Payment Gateway

### 5.1 เอกสารที่ต้องเตรียมยื่น

- หนังสือรับรองบริษัท (อายุไม่เกิน 6 เดือน)

- บัตรประชาชนกรรมการผู้มีอำนาจลงนามและ UBO
- ❓ **ใบจดทะเบียนตลาดแบบตรง** — PSP บางเจ้าขอ (เกี่ยวโยงกับข้อ 1.1)

### 5.2 ❓ ต้องถาม PSP ให้ชัดก่อนเซ็น

> รับชำระแบบ **cross-border online** จากผู้จ่ายที่อยู่ในจีนแผ่นดินใหญ่ได้หรือไม่
> (ไม่ใช่นักท่องเที่ยวจีนที่สแกนจ่ายในไทย) — เป็นคนละผลิตภัณฑ์กันโดยสิ้นเชิง

| ลำดับ | เรื่อง | ทำไมด่วน |
|---|---|---|
| 1 | **VAT 0% หรือ 7%** (ข้อ 2.1) | ตอบผิดแล้วขายไปทั้งปี = ย้อนเก็บ 7% + เบี้ยปรับ |

| 6 | **Positive list จีน** (ข้อ 4.1) | กระทบว่าของจะผ่านด่านหรือไม่ |
